# WASD Roadmap

This roadmap shows the current direction of the project. Priorities may change based on testing and community feedback.

## Now

### Dark Souls III

- [x] Live character stats
- [x] Equipment tracking
- [x] Item tracking
- [x] Boss tracking
- [x] Boss resistance information
- [x] Spoiler controls
- [x] Route guidance
- [x] NPC and missable guidance
- [x] Live route mapping
- [x] Session statistics
- [x] Post-session analysis
- [ ] Public beta packaging
- [ ] Installer
- [ ] External testing
- [ ] Release documentation

## Next

- Co-op partner state sharing
- Improved build recommendations
- Better session comparison
- More robust game-version detection
- Automatic update checking
- Accessibility and UI improvements

## Future game support

WASD is intended to become a game-agnostic companion platform.

Potential future games include:

- Elden Ring
- Dark Souls Remastered
- Dark Souls II
- Sekiro
- other community-requested games

Future game priorities will be influenced by community demand and technical feasibility.

## Community requests

Once the community channels are live, players will be able to suggest and vote on:

- new features
- supported games
- quality-of-life improvements
- additional statistics and analysis
