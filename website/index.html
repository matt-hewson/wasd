WASDWorld Awareness & State Display

WASD is a free, open-source companion for Dark Souls III with Seamless Co-op.

It tracks things like missed items, bosses, character stats and where you've been. There's an in-game overlay, a dashboard for your second monitor, and a session report for looking back at your run.

You can also control how much it tells you, so you don't have to spoil anything you haven't found yet.

What it shows

Use it however you prefer

There's a browser dashboard if you have a second monitor, a small overlay if you'd rather keep everything in-game, and a results page for looking back at your session.

You can use all three or just whichever ones you find useful.

1 2 3 4 5 6
  1. Your character: HP, FP, stamina, equip load and roll tier, and what one more point in each stat would give you.
  2. Unfound items, numbered, with a direction arrow, distance and height.
  3. The bosses here, with their weaknesses.
  4. The map of your trail, with deaths and bonfire rests.
  5. Your gear, with real attack rating and what its next upgrade needs.
  6. Route and progress, plus missable warnings for questline steps that you could get locked out of.

Surface · second monitor

The Live Page

Shows your character, gear, nearby items, bosses and trail, as you play.

Open localhost:8765 in any browser. It updates as you move, and route hints point you on when you're unsure where to go. No more alt-tabbing to a wiki every five minutes.

Safe by design

How WASD works

WASD reads information from the game's memory. It doesn't modify the game, inject code or interfere with its networking.

It only works with Seamless Co-op and won't attach to the normal online version of Dark Souls III.

I realise downloading something that reads game memory might raise a few eyebrows, so I've tried to be as transparent as possible about how it works. The project is open source, and the technical details are available on GitHub.

What it will never do

Written plainly, so it can be held to.

  1. Write to the game's memory.It only ever asks Windows for permission to read.
  2. Inject code into the game.No DLLs, no hooks, no patches.
  3. Touch the game's networking.It doesn't see, send or alter any online traffic.
  4. Run during normal online play.It refuses to attach unless Seamless Co-op is running.
  5. Send your data anywhere.The live page is served on 127.0.0.1 only.
  6. Ship any of the game's files.It reads item, map and name data from your own install.
Read-only
It opens the game process with read permission and nothing more.
Seamless Co-op only
Seamless Co-op runs without anti-cheat. WASD checks for it and won't attach to normal online Dark Souls III.
Local only
Everything stays on your PC (until I build co-op partner networking, optional feature). The live page listens on 127.0.0.1, so nothing else on your network can reach it.
No game files shipped
On first run it builds its item, map and name data from your own copy of the game.
Open source, GPL-3.0
Data it shows was checked against the game, and the technical notes document how each one is read.
An honest install
Installs for your Windows user only, with no admin prompt. Not code-signed yet, so SmartScreen will warn you. Each release lists a SHA-256 checksum.

WASD is unofficial. It isn't affiliated with or endorsed by FromSoftware, Bandai Namco, Valve, or the Seamless Co-op developers.

Install

Getting started

About two minutes. No admin rights needed.

  1. Download the installer

    Get the latest .exe from the releases page on GitHub. It's a pre-release, so expect rough edges and please report them.

  2. Check the checksum (optional, recommended)

    Each release lists a SHA-256 next to the file. In PowerShell:

    Get-FileHash -Algorithm SHA256 .\Downloads\WASD-*-setup.exe

    The hash should match the one on the release page exactly. If it doesn't, don't run it, and open an issue.

  3. Get past SmartScreen

    WASD isn't code-signed yet (certificates cost money), so Windows shows a blue warning box. That's expected.

    Check the GitHub release to make sure you are happy with proceeding before pressing "Run anyway".

    It is also recommended to verify the checksum in the previous step before proceeding.

    Windows protected your PC
    More info→Run anyway

  4. Start the game, then WASD

    Launch Dark Souls III through Seamless Co-op, then open WASD. On first run it reads item, map and name data from your install. Open localhost:8765 on your second monitor.

    Your settings and session history live in %LOCALAPPDATA%\WASD.

  5. Leaving, if you ever want to

    Uninstall from Settings → Apps → Installed apps → WASD. To remove your history too, delete %LOCALAPPDATA%\WASD.

Got it running? If it saved you a wiki tab or two, you can buy me a coffee on Ko-fi.

About

About WASD

WASD started as something I wanted for my own playthroughs.

I kept finding myself checking wikis to see what I'd missed, looking up boss weaknesses or trying to work out where I was supposed to go next. I figured it'd be useful to have that information available while playing, without having to constantly switch between windows.

I'm developing it on my own in my spare time, with help from Claude Code. I've used it extensively to build both the application and this website. I'm responsible for the ideas, decisions, testing and ongoing development, but I want to be upfront about the fact that AI has played a significant part in getting it built.

It's free and open source, and I'd like to keep improving it based on what people actually find useful. If you run into a problem or have an idea, GitHub is the best place to get in touch.

  • Found a bug? Open an issue on GitHub
  • Got an idea? Start a discussion
